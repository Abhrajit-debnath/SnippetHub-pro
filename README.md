# SnippetHub Pro

SnippetHub Pro is a subscription-based code snippet manager that helps developers organize, manage, and quickly access code snippets by language, tags, and projects.

---

## Features

- User authentication (signup/login).
- Role-based access control.
- Create, edit, delete code snippets.
- Organize snippets with tags and categories.
- Search snippets efficiently.
- Subscription-based feature access.
- Chat feature.

---

## Tech Stack

- Frontend: Next.js, React, Tailwind CSS  
- Backend: Next.js API Routes (Serverless Functions)
- Authentication: JWT-based  
- Database: (MongoDB)
